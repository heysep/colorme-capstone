# 도커 컴포즈 파일 [ MinIO ]

아래 내용은 간편한 서버 배포 및 관리를 위한 도커 컴포즈 설정 가이드입니다.

## 설명

파일의 분산 처리 및 관리를 위함

## 의존성

해당 파일은 다음과 같은 의존성이 존재 합니다.

- 도커
  - 도커 외부 네트워크
- 환경변수
  - MinIO 사용자 계정 (환경 변수 이름: MINIO_ROOT_USER)
  - MinIO 사용자 비밀번호 (환경 변수 이름: MINIO_ROOT_PASSWORD)

## 유의사항

컴포즈를 실행하였지만 컨테이너가 바로 꺼지는 경우 data_mnt_minio1~n 까지 폴더의 권한을 확인할 필요가 있음, `chmod -R 777 data_mnt_mino1~n` 명령어를 통해 권한을 부여하여 해결
